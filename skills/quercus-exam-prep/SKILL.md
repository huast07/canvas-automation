---
name: quercus-exam-prep
description: Tutor progressively for an exam using synced lecture notes and mapped exam scope.
---
Run `python3 study.py check-ready COURSE_ID` before starting. If lecture sync or exam mapping is missing, guide the student through quercus-lecture-notes and quercus-exam-scope first; check the saved scope is for the selected exam and disclose stale or incomplete sources. Calibrate to the problem categories and formats evidenced in course documents, not guessed exam weights. Start each topic with basic concepts and a concise worked example, then progress from simple questions to multi-step exam-level problems. Offer a short diagnostic and permit skipping. Invite an attempt, identify misunderstandings and use progressive hints and corrective feedback; reveal the full solution whenever requested. Verify calculations independently when feasible and label uncertain answers. Cite sources, show gaps, and never claim coverage or predict a grade. With the student's consent record attempts via `study.py record-attempt COURSE_ID PATH` using a local JSON object with `topic`, relevant feedback and `needs_review: true` when appropriate; the command assigns an ID and a default next-day review time. Use `study_plan.py review COURSE_ID` for due items; after the student reviews an item, `study.py review-attempt COURSE_ID ATTEMPT_ID --outcome correct` or `--outcome retry` schedules the next suggested review using an editable 1/3/7-day heuristic (not a mastery assessment) and allow the student to correct or delete attempts with `study.py update-attempt` or `study.py remove-attempt`; explain that it is stored in study-data.
