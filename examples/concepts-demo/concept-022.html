Laplace transform

Illustrative course: Differential equations · Transforms

Why this matters

Maps a time function to a function of a new variable.

Scope: unknown

From first principles

The Laplace transform expresses a function of time as an integral depending on a parameter s, when that integral converges.

Assumptions

Assume the functions and operations used below are defined under the stated conditions. Check the cited source for the full hypotheses.

Reasoning / derivation

For f(t) = e^(at), the definition gives ∫₀∞ e^(−st)e^(at)dt = ∫₀∞ e^(−(s−a)t)dt = 1/(s−a), provided s > a.

Example

With a = 2, the transform is 1/(s−2), for s > 2.

PROBLEM TYPE

Evaluate a Laplace transform

The transform is an improper integral whose convergence depends on s.

Reasoning / derivation

For e^(at), direct integration gives 1/(s−a) when s>a.

Worked example

Find the transform of e^(2t).

  1. Combine exponentials in the defining integral.
  2. Integrate e^(−(s−2)t) over [0,∞).
  3. The result is 1/(s−2) for s>2.
