Euler’s method

Illustrative course: Differential equations · Numerical methods

Why this matters

Uses one slope per step.

Scope: unknown

From first principles

A differential equation y′ = f(t, y) specifies the slope at each point. Starting from a known value, we can use that slope to estimate the value a small time step later.

Assumptions

Assume the functions and operations used below are defined under the stated conditions. Check the cited source for the full hypotheses.

Reasoning / derivation

For a short step h, the definition of derivative suggests [y(t + h) − y(t)] / h ≈ f(t, y(t)); rearranging gives y(t + h) ≈ y(t) + h f(t, y(t)). This is an approximation, not an exact equality in general.

Example

If y′ = t + y and y(0) = 1, one step of h = 0.5 gives y(0.5) ≈ 1 + 0.5(0 + 1) = 1.5.
