QUESTION CATEGORY 01

Estimating a solution with Euler’s method

Identify the current point, calculate its slope, and take one or more numerical steps.

Slope at a point

For y′ = f(t, y), f(t, y) gives the instantaneous slope at that point.

Reasoning / derivation. The derivative is the limiting rate of change. Substituting the current t and y into f gives the local rate specified by the equation.

  • Illustrative derivation for this demonstration; not a course lecture.

Step size and approximation

The step size h is the change in t used for each estimate. The resulting estimate need not equal the exact solution.

Reasoning / derivation. Using slope × horizontal change to approximate vertical change gives y(next) ≈ y(current) + h × slope.

Sources
  • Illustrative derivation for this demonstration; not a course lecture.

Worked example

For y′ = t + y, y(0) = 1, estimate y(1) using two Euler steps of h = 0.5.

  1. At t = 0 and y = 1, the slope is 0 + 1 = 1, so y₁ = 1 + 0.5(1) = 1.5.
  2. At t = 0.5 and y₁ = 1.5, the slope is 0.5 + 1.5 = 2, so y₂ = 1.5 + 0.5(2) = 2.5.
  3. After two steps t = 1, giving the estimate y(1) ≈ 2.5; this is not the exact value.

Practice progression

Start with one concept. First practise calculating f(t, y) at a given point and identifying a step size.

Combine concepts. Then combine slope evaluation, repeated steps and an interpretation of numerical error.

Illustrative lecture 1

Rate of change

If y(t) represents a quantity, its average rate of change over a short interval h is [y(t + h) − y(t)] / h. The derivative is the limit of that average as h approaches zero, when the limit exists.

Reasoning / derivation. For y(t) = t², [y(t + h) − y(t)] / h = [(t + h)² − t²] / h = 2t + h. As h approaches zero, the rate approaches 2t.

Example. At t = 3, y′(3) = 6. Over a very short interval, the value initially increases at about 6 units per unit of time.

Illustrative lecture 2

Euler’s method

A differential equation y′ = f(t, y) specifies the slope at each point. Starting from a known value, we can use that slope to estimate the value a small time step later.

Reasoning / derivation. For a short step h, the definition of derivative suggests [y(t + h) − y(t)] / h ≈ f(t, y(t)); rearranging gives y(t + h) ≈ y(t) + h f(t, y(t)). This is an approximation, not an exact equality in general.

Example. If y′ = t + y and y(0) = 1, one step of h = 0.5 gives y(0.5) ≈ 1 + 0.5(0 + 1) = 1.5.
