---
name: quercus-exam-scope
description: Map an exam's date, constraints, topic coverage and past problems from Quercus and student-provided materials.
---
Identify the course and exam. Run `python3 study.py inventory COURSE_ID`; inspect available syllabus, announcements, notes, instructor exam guidance and imported past exams. Ask the student for missing date, constraints or documents; use quercus-document-import for local additions. Read all usable sources with page/slide citations and disclose inaccessible, image-only or unreadable content. List date and timezone, format, permitted aids, confirmed topics, inferred topics, unknowns and conflicts. Catalog each identifiable past problem and subproblem with source, page, question number, categories, prerequisites, difficulty, confidence and solution availability. Do not treat historical frequency as confirmed scope or weight. Have the student review the result. Save it as a local JSON object with `topics` and `problems` arrays, plus date, constraints, sources, uncertainties and exam identifier, then run `python3 study.py save-scope COURSE_ID PATH`. Never put a token in the JSON.
