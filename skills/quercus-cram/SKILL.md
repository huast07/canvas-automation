---
name: quercus-cram
description: Guide a time-limited Quercus exam preparation session with triage, practice and feedback.
---
Ask for the course, exam time and minutes available. Locate the Quercus project and existing study-data, then run `python3 study.py check-ready COURSE_ID`. Before proposing a plan or practice, check that the saved scope is current and matches the selected exam; use quercus-exam-scope if it is unknown, incomplete, stale or for a different exam, even if the student did not explicitly request a scope search. Guide the student through lecture sync as needed, respecting their time budget. If scope cannot be established, disclose the blocker and label any provisional plan and practice as uncertain. Use `python3 study_plan.py cram COURSE_ID --exam ISO_TIME_WITH_OFFSET --minutes N` to calculate a feasible time budget, then use the documented scope and problem types to propose a time-boxed editable plan, prioritizing confirmed topics and essential prerequisites. State omissions, stale or missing sources and uncertain priorities. Start with a concise conceptual refresher and use quercus-exam-prep to guide progressively harder representative questions with hints and corrective feedback. Finish with a mixed mock and feedback if time permits; in a very short session use one or two representative questions and feedback instead of a full mock. Reserve time to review errors. Do not promise complete coverage or a grade.

Before tutoring or the diagnostic, use the concepts-page workflow in `quercus-exam-prep`: inspect the reviewed scope, lecture sources and question categories; build and open the local HTML page with a categorized visual mind map of all identified concepts and their labeled relationships, explanatory graphics, problem-type concepts, first-principles lecture explainers, derivations, examples, citations and explicit gaps. Tailor the level of detail and prioritization to the available time without omitting known categories silently. Start practice with individual prerequisite concepts, then combine them in question-category problems before the short mock. If sources or the saved scope are unavailable, report the blocker rather than inventing content; if browser opening fails, provide the saved local page path.
