---
name: quercus-study-planner
description: Create and revise a realistic exam study plan using spaced retrieval, practice and feedback.
---
Ask for exam date and timezone, available study time, existing obligations and optional accommodations. Use the exam scope and actual attempts when available; disclose gaps and distinguish self-reported confidence from observed performance. Use `python3 study_plan.py create COURSE_ID --exam ISO_TIME_WITH_OFFSET --start YYYY-MM-DD --days N --minutes N` to create an editable local draft when prerequisites and the required dates are available. Consecutive dates are a default; help the student edit the JSON to reflect actual availability. Use `python3 study_plan.py review COURSE_ID` for recorded attempts marked `needs_review`. Propose editable blocks: concept foundations, retrieval and guided practice, spaced review of mistakes, mixed problems after foundations, then a mock with enough time for feedback. Adapt to missed sessions and time constraints. Do not claim a fixed interval is optimal. Do not create calendar events or notifications unless the student explicitly requests them and a suitable integration is available.
