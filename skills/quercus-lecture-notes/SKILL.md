---
name: quercus-lecture-notes
description: Preview and download a selected Quercus course's lecture notes.
---
From the project root, run `python3 quercus.py download COURSE_ID --preview`, then `python3 quercus.py download COURSE_ID`. Identify the course via the courses command if needed. Use an existing QUERCUS_TOKEN; otherwise have the user run commands in their terminal, without sharing their token. Selection uses filenames and folders and can miss notes or include mislabelled material; report that and offer to inspect the preview. Existing files are skipped.
